# Data Tools Platform

Free online tools for CSV, Excel, JSON and data workflows.

Website: https://data-tools-platform.vercel.app/

## Overview

Data Tools Platform is a collection of free browser-based tools designed to help users validate, clean, convert and prepare data files for imports, reporting, automation and everyday workflows.

The project is focused on practical data utilities such as CSV validation, CSV cleaning, Excel conversion, JSON conversion and data preparation guides.

## Features

- CSV validation tools
- CSV cleaning tools
- CSV to JSON conversion
- Excel and spreadsheet utilities
- Data preparation guides
- SEO-friendly tool and guide pages
- Fast frontend experience built with Next.js

## Tech stack

- Next.js
- TypeScript
- TailwindCSS
- Vercel

## Project status

The platform is live and currently focused on SEO growth, indexing, topical authority and gradual improvement of existing tools and guides.
